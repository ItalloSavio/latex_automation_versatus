 DIAGNOSTIC GUIDE — ERROR PATTERNS AND THEIR FIXES
═══════════════════════════════════════════════════════════════

──────────────────────────────────────────────────────────────
 ERROR CLASS 1: SPECIAL CHARACTERS IN TEXT
 Signals: "Missing $ inserted", "Undefined control sequence",
          "Paragraph ended before \next was complete",
          "You can't use `\spacefactor'"

 Cause: A "text" element contains a raw LaTeX special character.

 Fix: In the "text" value, escape each special character:
   &  →  \&
   #  →  \#
   $  →  \$
   %  →  \%
   ^  →  \^{}
   _  →  \_
   {  →  \{
   }  →  \}
   ~  →  \~{}
   \  →  \textbackslash{}

 Example: "C# Programming" → "C\# Programming"
 Example: "100% Coverage"  → "100\% Coverage"
 Example: "f(x) = x^2"    → "f(x) = x\^{}2"

──────────────────────────────────────────────────────────────
 ERROR CLASS 2: COORDINATE OUT OF BOUNDS OR MALFORMED
 Signals: "Dimension too large", "Illegal unit of measure",
          "I can't find file", pgf arithmetic overflow

 Fix:
 - Clamp any X value outside [0.0, 21.0] to the nearest bound
 - Clamp any Y value outside [0.0, 29.7] to the nearest bound
 - If a coordinate is a string instead of a number, convert it
 - If radius ≤ 0, replace with 0.1
 - If radius > 21.0, clamp to 10.5

──────────────────────────────────────────────────────────────
 ERROR CLASS 3: INVALID OR UNDEFINED COLOR
 Signals: "Package xcolor Error: Undefined color",
          "Package pgfkeys Error: .../color=...",
          "undefined color name"

 Fix:
 - All "color" values must be "#RRGGBB" (6 hex digits, case-insensitive)
 - Examples of valid: "#1A2B3C", "#ffffff", "#000000"
 - Examples of INVALID: "#1A2B", "#GGHHII", "rgb(255,0,0)", "red !50"
 - If a color value is invalid, replace with the closest reasonable hex value
 - Named colors (black, white, red, blue, green) are allowed as-is

──────────────────────────────────────────────────────────────
 ERROR CLASS 4: FONT SIZE ISSUES
 Signals: "Illegal parameter", "Missing number, treated as zero",
          "Font ... not loaded: Not loadable"

 Fix:
 - "font_size" must be a positive number between 4 and 288 (in pt)
 - If font_size is 0 or negative: replace with 12
 - If font_size > 288: clamp to 72
 - If font_size is a string: convert to a number

──────────────────────────────────────────────────────────────
 ERROR CLASS 5: EMPTY OR NULL TEXT
 Signals: "Missing \endcsname inserted", "Extra }, or forgotten $",
          empty node warnings

 Fix:
 - "text" fields must be non-empty, non-null strings
 - If a text field is empty (""), replace with the likely content
   based on context (e.g., the book title from metadata)
 - As a last resort, replace with a descriptive placeholder like "—"

──────────────────────────────────────────────────────────────
 ERROR CLASS 6: TikZ / PGF SYNTAX ISSUES
 Signals: "Package pgfkeys Error: I do not know the key",
          "Package tikz Error: Giving up on this path",
          "Missing } inserted (TikZ)"

 Fix:
 - Check that "anchor" is one of the allowed values:
   center, north, south, east, west, north west, north east,
   south west, south east, base, base west, base east
 - Check that "font_weight" is one of: normal, bold, italic, bold_italic
 - Ensure no field contains raw LaTeX commands except the allowed
   font commands (\bfseries, \itshape) which the converter handles

──────────────────────────────────────────────────────────────
 ERROR CLASS 7: LINE WIDTH / DIMENSION ISSUES
 Signals: "Illegal unit of measure (pt inserted)"

 Fix:
 - "width" for line elements must be a positive float (in pt)
 - Valid range: 0.1 – 50.0 pt
 - If zero or negative: replace with 0.4
 - If it's a string like "2pt": extract the numeric part (2.0)
