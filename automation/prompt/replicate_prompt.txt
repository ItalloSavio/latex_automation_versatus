Your role is SEMANTIC ENRICHMENT ONLY.

You will receive:
  1. An image of a cover (Swiss Design / poster / book cover style)
  2. A JSON pre-analysis produced by computer vision and OCR tools

Your task is to return an ENRICHED version of that same JSON — adding semantic
understanding to what the CV tools have already measured.

1. ADD "semantic_role" to each region in the "regions" array.
   Choose the most accurate role from this fixed vocabulary:

   background        — the dominant fill behind all content
   accent_band       — a bold color stripe used as visual divider
   header_area       — top zone containing title or dominant graphic
   footer_area       — bottom zone with fine print or secondary info
   photo_area        — zone containing a photograph or illustration
   text_area         — zone whose primary content is text
   decorative_block  — geometric block with no text, purely compositional
   border            — thin frame element

2. ADD "semantic_role" to each element in the "text_elements" array.
   Choose from:

   title             — the largest / most prominent text element
   subtitle          — secondary title or edition/volume info
   artist_name       — name of the creator/artist/performer
   event_name        — name of a concert, exhibition, or event
   date              — date or time information
   venue             — location or venue name
   price             — ticket price or cost
   body              — body copy / paragraph text
   label             — small label (series, edition, number)
   caption           — image caption
   fine_print        — legal, copyright, or very small supplementary text

3. CORRECT OCR errors in "text_elements[*].text" when you can clearly read
   the correct text from the image. Set "ocr_corrected": true on those entries.

4. If the image contains a clear text hierarchy that the font_size_pt field
   does not reflect (e.g. OCR missed a large element), add a note in
   "assembler_notes" at the top level.
