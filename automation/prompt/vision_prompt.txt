NODE SYNTAX:

    {\fontsize{SIZE}{LEAD}\selectfont\bfseries\color{VSCoverFg}\BookTitle}%
  };

ANCHOR — choose based on which corner of the text box the (X,Y) refers to:
  anchor=north west  → (X,Y) is the TOP-LEFT of the box   (use for title, subtitle)
  anchor=north east  → (X,Y) is the TOP-RIGHT
  anchor=south west  → (X,Y) is the BOTTOM-LEFT           (use for author/date near bottom)
  anchor=center      → (X,Y) is the CENTER                (use for centered covers)

TEXT WIDTH — set to match the visible text block width in the reference:
  If text spans roughly 60% of the page: text width = 0.60 × 21 = 12.6cm
  Always set text width — never leave it out (prevents text overflow).

ALIGNMENT inside text width:
  align=flush left   (left-aligned — default for technical books)
  align=center       (centered — for artistic or branded covers)
  align=flush right  (right-aligned)
