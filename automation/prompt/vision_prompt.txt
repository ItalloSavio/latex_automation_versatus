═══════════════════════════════════════════════════════════════
 COVER_LAYOUT ESTIMATION RULES
═══════════════════════════════════════════════════════════════
After completing Block 1, output Block 2 using these guidelines:

VSCoverTopMargin — vertical gap from page TOP to where the main title/text
  block BEGINS, in cm. A4 height = 29.7 cm, top = 29.7.
  If text starts 18% from top: 0.18 × 29.7 ≈ 5.3 cm.
  Range: 3.0 cm (text near top) to 12.0 cm (text in lower half).
  Default: 5.3cm. Use default if no text zone is visible.

VSCoverLeftIndent — distance from the LEFT EDGE of the usable text area to
  the text block, in cm. Use 0.0cm if text starts at the left margin.
  For centered text: estimate half of (21 - text_block_width_cm). Range: 0.0–6.0 cm.
  Default: 2.05cm.

VSCoverTextWidth — fraction of the page text area the text block occupies
  (decimal 0.50–0.95). If text spans ~80% of the column width: 0.80.
  Default: 0.80.

VSCoverTitlePt / VSCoverTitleLeadPt — estimated title font size in pt and its
  leading. Title is usually the LARGEST text on the cover. If it looks very
  large (>30% of page width per character row): 32–36pt. Medium: 24–28pt.
  Leading is usually 1.15–1.25× the font size (e.g. TitlePt=28 → LeadPt=34).
  Defaults: 28 / 33.

VSCoverSubtitlePt / VSCoverSubtitleLeadPt — subtitle/tagline font size.
  Usually 50–65% of title size. Defaults: 15 / 20.

VSCoverTitleAlign — text alignment WITHIN the text block:
  \raggedright  (left-aligned, most common for technical books)
  \centering    (centered, common for artistic or branded covers)
  \raggedleft   (right-aligned, uncommon)
  Default: \raggedright.
